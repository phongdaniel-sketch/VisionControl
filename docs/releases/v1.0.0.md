# VisionControl v1.0.0

First stable Windows release of VisionControl's local gesture and Vietnamese voice
control experience.

## Highlights

- Webcam mouse control, calibration, gestures, keyboard shortcuts, tray mode, and startup options.
- Local Vietnamese Voice Control with optional Gemini transcription and spoken responses.
- Timers with countdown and alarm, live weather, date/time, Copy, Paste, Close Window, and Lock Screen.
- Copy, Paste, and Close Window keep the current Start/Pause state.
- Lock Screen pauses gesture input until the user explicitly presses Start.
- Windows executable includes File Version 1.0.0.0 and Product Version 1.0.0.

## Download

Download `VisionControl-1.0.0-windows-x64.zip`, extract the complete folder, and run
`VisionControl.exe`. Keep the `_internal` directory beside the executable.

Verify the archive against `VisionControl-1.0.0-windows-x64.zip.sha256` before use.

## Signing status

This release is unsigned unless the GitHub asset notes explicitly say otherwise. Windows
SmartScreen may warn on unsigned or low-reputation downloads. No private API keys, voice
recordings, logs, or personal settings are included in the bundle.
